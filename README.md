•	transaction_id — уникальный идентификатор

•	transaction_amount — сумма

•	transaction_description — описание
•	merchant_name — название магазина

 Ответы на контрольные вопросы
1. Какие методы массивов используются?
Основные методы:
•	map() — преобразование элементов массива
•	filter() — фильтрация элементов
•	reduce() — агрегирование данных
•	find() — поиск элемента
2. Как сравнивать даты в JavaScript?
Для сравнения дат используется объект Date:
new Date(date1) > new Date(date2) 
3. Разница между map(), filter() и reduce()
•	map() — изменяет каждый элемент массива
•	filter() — отбирает элементы по условию
•	reduce() — объединяет массив в одно значение
